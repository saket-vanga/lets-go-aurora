# Chasing Aurora

Trip companion for the 13-day Finland · Norway · Sweden + Lofoten aurora tour (25 Nov – 7 Dec).
Live countdowns, day-by-day plan, flights, aurora log and emergency numbers. Installable on iPhone
(Safari → Share → Add to Home Screen) and works offline after the first visit.

- `app.html` – the app source
- `build/wrap.sh` – wraps it into `docs/` (served by GitHub Pages)
- `build/make.py` – generates the app icons
